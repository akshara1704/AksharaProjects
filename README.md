# Projects

A collection of software development projects built using Python, Flask, Selenium, Tkinter, MySQL, and Google Generative AI.

## 🚀 Projects

### 1. Automated Operation App
**Technologies:** Selenium • Tkinter • Chrome WebDriver

- Built a GUI-based desktop application to perform automated browser workflows using Selenium.
- Automated tasks including **login, navigation, and data extraction**, simulating real-world business processes.
- Integrated Tkinter to provide a simple graphical interface for controlling automation workflows.
- Used Chrome WebDriver for browser-based automation.

---

### 2. Employee Database Management System
**Technologies:** Flask • MySQL • Python

- Developed a **CRUD-based employee management system** with a Flask backend and MySQL database integration.
- Implemented **session management and user authentication** for secure application workflows.
- Added **regex-based input validation** to improve data accuracy and validation.
- Designed the application to perform database operations through a Python-based web interface.

---

### 3. Resume Analyzer and Interview Question Generation App
**Technologies:** Flask • Python • Google Generative AI

- Created an **AI-integrated web application** for analyzing uploaded resumes and generating personalized interview questions.
- Integrated **Google Generative AI** to process user-provided content and generate relevant outputs.
- Implemented features including **object recognition, metadata extraction, and text analysis from images**.
- Built the application using Flask for backend processing and web application development.

---

## 🛠️ Technologies Used

- **Database:** MySQL
